# 📊 Simulasi Nilai Gabungan Siswa

Aplikasi sederhana berbasis Python menggunakan Streamlit untuk membantu guru dalam mengelola dan menampilkan data nilai siswa secara mudah dan interaktif.

---

## 🎯 Tujuan Aplikasi
Aplikasi ini dibuat untuk:
- Mempermudah pengolahan data nilai siswa
- Menampilkan data dalam bentuk tabel yang rapi
- Membantu guru dalam analisis nilai sederhana

---

## 🚀 Fitur Utama
✅ Upload file data siswa (format CSV)  
✅ Menampilkan data dalam bentuk tabel  
✅ Tampilan interaktif berbasis web  
✅ Mudah digunakan tanpa instalasi rumit
